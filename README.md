# Лабораторная работа № 5: Разработка базового SPA на React

## Описание страниц и компонентов

### 1. Навигационная панель (TabBar)

Расположена в нижней части экрана и содержит 4 пункта:

* **Лента** (`/`) — просмотр нутриентов в полноэкранном режиме с фоновым видео.
* **Добавление** (заглушка) — в данной лабораторной работе страница не открывается, подготовлена для будущих релизов.
* **Плитка** (`/nutrients_grid`) — страница со списком карточек нутриентов.
* **Вход** (заглушка) — страница авторизации, зарезервирована для следующих лабораторных работ.

### 2. Страница плитки

Главная страница приложения для обзора всех доступных нутриентов в виде сетки карточек.

* **Поля и элементы:**
  * **Фильтр-слайдер** («Норма»): Два сопряженных ползунка для выбора минимального и максимального значения дневной нормы (диапазон 0–150).
  * **Текстовый вывод диапазона**: Отображает текущие выбранные значения ползунков.
  * **Кнопка «НАЙТИ»**: Кнопка отправки формы, по нажатию которой выполняется локальная фильтрация списка карточек.
* **Карточка нутриента:**
  * Содержит дефолтное изображение (`nutrients_default_image.jpg`), название нутриента, количество лайков и условную кнопку «Удалить» (выполняет роль заглушки).
  * Клик по любой области карточки открывает её в Ленте для детального просмотра.

### 3. Страница ленты

Полноэкранный просмотр нутриентов в стиле вертикальной ленты.

* **Поля и элементы:**
  * **Медиаплеер**: Фоновое видео (`nutrients_default_video.mp4`).
  * **Заголовок и лайки**: Название нутриента и счетчик лайков.
  * **Кнопка «Далее»** (стрелка): Переключает на следующий нутриент в отфильтрованном списке (с циклическим возвратом к началу).
  * **Блок описания**: Текст описания нутриента с выравниванием по левому краю и интерактивной кнопкой раскрытия длинного текста «Ещё» / «Скрыть».
  * **Параметры**: Значение дневной нормы нутриента.
