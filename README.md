# Система учета нутриентов (Фронтенд)

## Описание проекта
SPA-приложение на React + TypeScript (сборка Vite) для просмотра каталога нутриентов. В рамках Лабораторной работы №5 реализован интерфейс для "Гостя" без подключения к бэкенду (данные берутся из Mock-коллекции).

## Доступные страницы и кнопки
- **Лента**: Вертикальный просмотр одной карточки. Содержит фоновое видео по умолчанию, кнопку `Далее` (Стрелка вправо) для перелистывания массива, чекбокс `Ещё/Скрыть` для разворачивания описания.
- **Плитка**: Отображение всех карточек списком. Реализован двойной ползунок (слайдер) для задания диапазона нормы. Фильтрация массива происходит строго по нажатию на кнопку `НАЙТИ`. При клике на любую карточку происходит переход в Ленту.
- **Нижняя навигационная панель**: Содержит 4 пункта (Лента, Добавление, Плитка, Вход). В 5-й лабораторной работе кнопки "Добавление" и "Вход" программно отключены. На плитке присутствует зеленая кнопка "Удалить" (заглушка).

## Запуск проекта
Установите зависимости: `npm install`
Запустите сервер: `npm run dev` (порт 3000)
