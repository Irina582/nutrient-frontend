# Лабораторная работа № 5: Разработка базового SPA на React

## Описание страниц и компонентов

### 1. Страница плитки

Главная страница приложения для обзора всех доступных нутриентов в виде сетки карточек.

* **Поля и элементы:**
  * **Фильтр-слайдер** («Норма»): Два сопряженных ползунка для выбора минимального и максимального значения дневной нормы (диапазон 0–150).
  * **Текстовый вывод диапазона**: Отображает текущие выбранные значения ползунков.
  * **Кнопка «НАЙТИ»**: Кнопка отправки формы, по нажатию которой выполняется локальная фильтрация списка карточек.
* **Карточка нутриента:**
  * Содержит дефолтное изображение (`nutrients_default_image.jpg`), название нутриента, количество лайков и условную кнопку «Удалить» (выполняет роль визуальной заглушки, запросы к БД не выполняются).
  * Клик по любой области карточки открывает выбранный нутриент в Ленте для детального просмотра.

### 2. Страница ленты

Полноэкранный просмотр нутриентов в стиле вертикальной ленты (по аналогии с TikTok / Reels).

* **Поля и элементы:**
  * **Медиаплеер**: Фоновое видео (`nutrients_default_video.mp4`).
  * **Заголовок и лайки**: Название нутриента и локальный счетчик лайков.
  * **Кнопка «Далее»** (стрелка): Переключает на следующий нутриент в отфильтрованном списке (с циклическим возвратом к началу массива, если достигнут конец). Переключение происходит без изменения маршрута.
  * **Блок описания**: Текст описания нутриента с выравниванием по левому краю и интерактивной кнопкой раскрытия длинного текста «Ещё» / «Скрыть».
  * **Параметры**: Значение дневной нормы нутриента.

### 3. Страница входа (Авторизация)

*Примечание: В рамках 5-й лабораторной работы маршрутизация на данную страницу отключена (кнопка в панели навигации неактивна), так как методы API для аутентификации еще не подключены.*

В полнофункциональной версии системы страница предназначена для входа создателей в свой профиль и содержит:
* **Форму авторизации** с текстовыми полями для ввода логина (`username`) и пароля (`password`).
* **Кнопку «Войти»** для проверки данных и инициализации сессии пользователя.

### 4. Страница добавления нутриента (Черновик)

*Примечание: В рамках 5-й лабораторной работы маршрутизация на данную страницу отключена (кнопка в панели навигации неактивна).*

В полнофункциональной версии это рабочий интерфейс нутрициолога для создания новой записи. Страница должна содержать:
* **Блоки загрузки медиафайлов**: интерфейс выбора изображения (`image/*`) и видео (`video/*`) с локального устройства, расположенные друг под другом.
* **Форму параметров**: поля для ввода названия нутриента, его описания, дневной нормы и единиц измерения.
* **Кнопки управления**: «Далее» (для сохранения промежуточного черновика) и «Опубликовать» (для перевода нутриента в общий доступ).
