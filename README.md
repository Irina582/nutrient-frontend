# Лабораторная работа № 5: Разработка базового SPA на React

## Описание страниц и компонентов

### 1. Навигационная панель (TabBar)

Расположена в нижней части экрана и содержит 4 пункта. Два из них являются активными маршрутами, а два добавлены исключительно в качестве визуальных элементов интерфейса (заглушек) по требованиям предметной области, переходы по ним в рамках данной работы заблокированы:

* **Лента** (`/`) — активная вкладка. Просмотр нутриентов в полноэкранном режиме с фоновым видео.
* **Добавление** — визуальная заглушка. При клике навигация не происходит.
* **Плитка** (`/nutrients_grid`) — активная вкладка. Страница со списком карточек нутриентов.
* **Вход** — визуальная заглушка. При клике навигация не происходит.

### 2. Страница плитки

Главная страница приложения для обзора всех доступных нутриентов в виде сетки карточек.

* **Поля и элементы:**
  * **Фильтр-слайдер** («Норма»): Два сопряженных ползунка для выбора минимального и максимального значения дневной нормы (диапазон 0–150).
  * **Текстовый вывод диапазона**: Отображает текущие выбранные значения ползунков.
  * **Кнопка «НАЙТИ»**: Кнопка отправки формы, по нажатию которой выполняется локальная фильтрация списка карточек.
* **Карточка нутриента:**
  * Содержит дефолтное изображение (`nutrients_default_image.jpg`), название нутриента, количество лайков и условную кнопку «Удалить» (выполняет роль визуальной заглушки, запросы к БД не выполняются).
  * Клик по любой области карточки открывает выбранный нутриент в Ленте для детального просмотра.

### 3. Страница ленты

Полноэкранный просмотр нутриентов в стиле вертикальной ленты (по аналогии с TikTok / Reels).

* **Поля и элементы:**
  * **Медиаплеер**: Фоновое видео (`nutrients_default_video.mp4`).
  * **Заголовок и лайки**: Название нутриента и локальный счетчик лайков.
  * **Кнопка «Далее»** (стрелка): Переключает на следующий нутриент в отфильтрованном списке (с циклическим возвратом к началу массива, если достигнут конец). Переключение происходит без изменения маршрута (URL остается прежним).
  * **Блок описания**: Текст описания нутриента с выравниванием по левому краю и интерактивной кнопкой раскрытия длинного текста «Ещё» / «Скрыть».
  * **Параметры**: Значение дневной нормы нутриента.

### 4. Страница входа (Авторизация)

*В рамках 5-й лабораторной работы страница физически не реализована.* Элемент в панели навигации служит исключительно для демонстрации полного состава меню будущего приложения. Маршрутизация на данную страницу отключена.

### 5. Страница добавления нутриента (Черновик)

*В рамках 5-й лабораторной работы страница физически не реализована.* Элемент в панели навигации служит интерфейсной заглушкой, отражающей роль «Создателя» (нутрициолога). Маршрутизация на данную страницу отключена.
